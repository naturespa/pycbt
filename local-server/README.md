# pycbt 校内成績サーバ

`server.js` と `admin.html` を **先生PCの `C:\cbt`** にコピーします。成績データ `pycbt.db` は GitHub には置きません。

## 現行サーバからの更新

1. 実行中の `node server.js` を `Ctrl+C` で終了します。
2. `C:\cbt\pycbt.db` を別の安全な場所へバックアップします。終了後に `pycbt.db-wal` と `pycbt.db-shm` が残っている場合は、それらも一緒にバックアップします。
3. このフォルダの `server.js` と `admin.html` を `C:\cbt` にコピーします。既存の `server.js` は上書きし、`pycbt.db` は上書きしません。
4. 未導入の場合だけ `cd C:\cbt`、`npm install express better-sqlite3 cors` を実行します。
5. `cd C:\cbt`、`node server.js` で起動します。
6. **先生PCで** `http://localhost:3000/admin` を開きます。以前の成績を確認し、CSVを出力します。

GitHub Pages の生徒用サイトは既存の `http://172.17.156.65:3000` へ送信します。先生PCのIPアドレスが変わった場合は、公開側 `app.js` の `LOCAL_SERVER` を更新してください。`/api/health` はLANから接続確認できます。

## 管理画面

- クラスで絞り込んで提出状況を確認できます。名簿を未登録のため「未提出者」は表示されません。
- 標準では受験番号ごとに最後に保存した1件を表示します。チェックを外すと過去の記録も表示します。
- 現在の表示条件を反映したCSVを出力します。A～Fの得点は保存済みの解答から集計します。
- 管理画面、成績一覧API、CSV出力は先生PCの `localhost` からのみ利用できます。生徒PCからの成績提出と接続確認は継続します。

## 運用上の範囲

サーバが得点を再採点する仕組みはまだありません。ブラウザから送られた点数を保存するため、本番の成績確定前には提出件数・重複・得点を確認してください。成績の外部公開や、校内の別端末から管理画面を開く運用には対応していません。
